##tipo de lista usada en cada uno
En el 1er problema usé la lista simple, pero adaptada como Cola, ya que este es un problema de cola, donde el primero en entrar es primero en salir.
En el 2do problema usé listas simples, ya que implementé nodos enlazados secuencialmente para procesar transacciones y turnos en orden de llegada.
En el 3er problema usé listas simples, ya que utilicé una estructura lineal de nodos simples.
En el 4to problema usé listas simples ordenadas, ya que se deben de manejar los nodos enlazados para el registro y almacenamiento de los elementos evaluados.

##cómo compilar y ejecutar
1. Primero debes de irte a la carpeta donde se encuentre el problema que quiera ejecutar
2. ejecutar el comando "javac *.java" para que compile todos los archivos del problema.
3. ejecutar el comando "java Main" para que se ejecute correctamente
